## 钓鱼

- **游戏人数：** 5-15
- **原作：** 彩虹菜鸟

### 游戏简介
- **鱼**为食物而来，饲料亦或是同胞的躯体，只要不被饿死就是胜利。
- **渔夫**为不空军而来，为了给对象交待而来，只要带着鱼回家就是胜利。
- 一共两口池子并列排放，分别为 **A 池**与 **B 池**。开局全员降临 A 池。

### 一、身份与人数配置
- **鱼与渔夫的身份全程公开**，所有人的肥度、位置、鱼饵与公斤数同样公开。
- 渔夫数量由人数决定，其余玩家全部为鱼：
  + **5-6 人：** 4-5鱼 + 1渔夫
  + **7-9 人：** 5-7鱼 + 2渔夫
  + **10-13 人：** 7-10鱼 + 3渔夫
  + **14-15 人：** 10-11鱼 + 4渔夫
- **随机模式（默认）：** 全部玩家进入游戏后随机分配身份。
- **任命模式：** 开局随机一名玩家获得任命权，需**一次性**任命符合本局配置的全部渔夫（可以任命自己）。

### 二、回合流程
第 1 回合全员强制位于 A 池，没有洄游阶段；此后每回合依次进行：

1. **【洄游】** 私聊选择前往的水池或停留原地 → 公示全员位置
2. **【下饵】** **渔夫**私聊选择本回合行动 → **全场公示**各渔夫的行动与具体鱼饵
3. **【择钩】** **鱼**私聊选择咬钩，或捕猎 → **全场公示**每个钩上正在争抢的**鱼**
4. **【角力】** **鱼**私聊提交投入的体力、渔夫私聊提交垂钓的猜测，**互不知晓**
5. **【结算】** 公开全部选择与结果

游戏共 **8 回合**。全部**鱼**离场、或全部**渔夫**的鱼饵耗尽时，游戏结束。

### 三、鱼
- 每条鱼**初始肥度 5**，每回合结束自然消耗 **1** 点肥度。
- 肥度**达到 -3** 陷入**极度饥饿**；肥度**达到 -5** 时饿死腐烂，并为所在水池留下 **1 点永久瘟疫值**。
- **瘟疫当回合即刻生效**：每 1 点瘟疫使该池每回合的自然消耗**增加 0.5**。若追加的消耗又饿死了新的鱼，瘟疫会继续追加。两池的瘟疫互不相通。
- **洄游**：更换水池消耗 **0.5** 肥度，**本阶段立即扣除**，可能陷入饥饿或饿死。
- **咬钩**：本池只要有钩，鱼就必须咬住其中一个，或改为捕猎。随后私聊提交投入的**体力**，范围 **0 ~ 5**（0.5 的倍数，可以为 0）。
    + 渔夫**未能钓上鱼**时：由投入体力**最高**的鱼平分鱼饵的营养；回合结束时扣除各自投入的体力，**包括吃到鱼饵的鱼**，随后再扣自然消耗。
    + 渔夫**成功钓上鱼**时：此钩下所有鱼**都不消耗体力**，也**无人**吃到鱼饵；被钓上的鱼直接淘汰，且不再有自然消耗。
- **捕猎**：当同池出现极度饥饿的鱼时，**未陷入极度饥饿**的鱼可以放弃咬钩，转而捕猎其中**一条**。被吞噬的鱼不会留下瘟疫。
    + 捕猎与咬钩**只能二选一**，捕猎者本回合不参与任何鱼饵的争抢。
    + 需猜测目标为争抢鱼饵投入的体力。猜错则一无所获；猜中则目标本回合的行动**完全作废**，随后被吞噬淘汰，**所有猜中者平分 3 点肥度**。
    + **本池若没有任何鱼钩**，则无需猜测，目标被直接吞噬。

### 四、渔夫
- 初始鱼饵 **初级 ×3**（2 肥力）、**中等 ×2**（4 肥力）、**高等 ×1**（6 肥力）
- 每回合三选一：
    + **钓鱼**：选择一个鱼饵下钩并公示。**无论钓上与否，该鱼饵必定消耗**。
    + **挖饵**：**仅限身处 B 池**，消耗整个回合挖得一个**沙虫**（5 肥力，与其他鱼饵用法相同），**全局限 2 次**。
    + **放弃钓鱼**：**仅在本池无鱼或自己无饵时**可用。**本池有鱼且自己有饵时必须下钩**，不得以任何形式放弃（挖饵不受此限制）。
- **垂钓**：猜测咬住鱼钩的鱼投入的体力数，范围 **0.5 ~ 5**（0.5 的倍数）。
    + 猜中则**投入该体力的鱼全部**被钓上淘汰，同时此钩下无鱼吃到鱼饵。
    + **猜测 5 时，投入 0 与 5 的鱼会一并被钓上。**
    + 若无鱼咬钩则无需猜测，鱼饵照常消耗。
- 被钓上的鱼按照肥度计算**公斤**数，肥度 ≤ 0.5 的鱼统一按 0.5 公斤计。

### 五、胜负与计分
- **鱼：** 存活到终局即得 **30** 分；终局肥度**第一名** 追加 **25** 分，**第二名**追加 **15** 分；若**全局无一条鱼被钓上**，存活的鱼再追加 **20** 分的群体胜利分。
- **渔夫：** 钓上过鱼即得 **30** 分；**公斤数最多**的渔夫追加 **25** 分。
- **中途退出：** **-50** 分。

### 六、超时与退出
- **超时**默认按以下行动处理：
    + 洄游：停留原地
    + 下饵：本池有**鱼**且自己有饵时，随机挑一个鱼饵下钩；否则放弃钓鱼
    + 择钩：本池有钩时随机咬住其中一个，且不会发起捕猎
    + 角力：**鱼**默认投入 0 体力（捕猎者默认猜测 0），**渔夫**默认猜测 5
- **中途退出：**
    + **鱼**退出即死亡，且为所在水池留下 1 点**瘟疫**；本回合行动一律作废。
    + **渔夫**退出后立即离场，但其本回合**已公示的鱼钩仍会收线**，按猜测 5 结算。其此前钓上的鱼依然计入「是否有鱼被钓上」的判定。
    + **全部渔夫退出**时游戏立即结束。
